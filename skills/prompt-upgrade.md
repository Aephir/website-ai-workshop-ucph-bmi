# Prompt Upgrade — turn a rough ask into a ready-to-send prompt

Turn a rough prompt, half-formed idea, or task description into one finished, copy-paste-ready prompt for the AI tool the user is about to use.

## Hard rules

- Never produce placeholders such as `[fill in here]`, `{topic}`, or `<your input>`.
- Ship a complete prompt from the real content provided, or write a self-contained prompt that naturally requests missing input.

State the goal and output format, name the audience, use explicit constraints, and include concrete examples when tone or structure matters. For high-stakes outputs, add a closing self-check. Ask clarifying questions only when getting it wrong is costly or genuinely ambiguous.

## Output

A single ready-to-send prompt, without a preamble or explanation unless requested.
