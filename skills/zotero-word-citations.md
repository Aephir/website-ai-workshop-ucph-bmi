# Zotero field-linked citations in Word (.docx)

Load this skill at the start of any task producing a document with citations or a reference list.

## Before writing references

Make one lightweight Zotero connectivity check. If it succeeds, build live field-linked citations. In an interactive session, stop and ask if Zotero is unreachable whether to connect it or fall back to plain references. In an autonomous session, use plain references and flag that a live-linking pass remains.

## Practical recipe

Use Zotero `CSL_CITATION` and `CSL_BIBLIOGRAPHY` fields with embedded item data. Prefer harvesting a real Zotero-authored item-data blob over mapping one by hand. After delivery, open the document in Word with Zotero and click Refresh before treating citations as final.

The skill covers citation groups, bibliography field structure, grounding assumptions, known limitations, and troubleshooting malformed Word fields.
