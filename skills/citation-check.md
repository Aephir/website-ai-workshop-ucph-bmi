# Citation Check

Verify that citations and references in a document are trustworthy rather than merely well formatted.

## The five checks

1. Confirm that each reference exists, using the user's reference library first and external verification when needed.
2. Check authors, year, title, and venue against the actual source.
3. Confirm that the citation is placed next to the claim it supports.
4. Read the source, preferring full text, and confirm that it genuinely supports the claim.
5. Check retraction and expression-of-concern status.

Fix metadata and misplaced citations directly when possible. Flag unsupported or apparently fabricated references for human judgment. Always report a findings table and rank references that remain unverified because full text was unavailable.
