# Worst-ideas-first

Ask for the worst version of something before asking for a good one. Bad ideas are easier to generate and easier to diagnose than good ones — once you can name exactly *what* makes an idea bad, inverting that property is a fast route to a genuinely good one, instead of a generic "make it better."

## The pattern

1. Ask for 3-5 deliberately bad versions of whatever you're working on.
2. For each one, name in a few words what specifically makes it bad.
3. Ask for a version that inverts each named flaw.

## Example prompt

> I need to open a talk to group leaders about using AI in their research. Give me 4 deliberately terrible opening lines for this talk — the kind that would lose the room in the first ten seconds. For each one, name in 5 words or less what makes it bad. Then write one strong opening line that inverts all four flaws at once.

## Why this works better than asking directly for a good version

"Give me a good opening line" returns something generic and hard to critique — you're evaluating a single answer with no reference point. Bad-then-flip gives you the failure modes explicitly named, so the final version is a direct fix to known problems rather than a guess at what "good" means.
