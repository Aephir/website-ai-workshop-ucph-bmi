# How to use this set

1. Pick **one** base prompt and paste it as your first message in a fresh project/space/notebook/chat:
   - `11-memory-vault-single-project.md` — memory scoped to this one project only. Works in some form on all five platforms.
   - `12-memory-vault-universal.md` — one memory shared across every project you have on that platform. Needs a connector outside any single project — not every platform, plan, or person will want this (see its own cloud-storage caveat before choosing it).
2. If you don't already have the container/connector the base prompt needs, paste `14-addon-setup-assistant.md` first and let the assistant walk you through it.
3. Once the base prompt is working and you like it, optionally paste `13-addon-skill-packager.md` to try turning it into something that doesn't need re-pasting every session. Not guaranteed to work on your platform — that's the point of trying it.

Don't run the single-project and universal prompts in the same project — pick the one that matches what you're actually trying to do.

The live Setup page (workshop.walden.dk → Setup) covers this same ground for the workshop's own project: a ready-to-paste memory-vault prompt plus Walden's actual Global Instructions and Project Instructions text. Use these numbered files when you want the generic, adapt-it-yourself version instead — for a different project, or to understand what the Setup page's prompt is actually doing.
