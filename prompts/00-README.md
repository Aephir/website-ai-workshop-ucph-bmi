# How to use this set

1. Pick **one** base prompt and paste it as your first message in a fresh project/space/notebook/chat:
   - `01-memory-vault-single-project.md` — memory scoped to this one project only. Works in some form on all five platforms.
   - `02-memory-vault-universal.md` — one memory shared across every project you have on that platform. Needs a connector outside any single project — not every platform, plan, or person will want this (see its own cloud-storage caveat before choosing it).
2. If you don't already have the container/connector the base prompt needs, paste `04-addon-setup-assistant.md` first and let the assistant walk you through it.
3. Once the base prompt is working and you like it, optionally paste `03-addon-skill-packager.md` to try turning it into something that doesn't need re-pasting every session. Not guaranteed to work on your platform — that's the point of trying it.

Don't run 01 and 02 in the same project — pick the one that matches what you're actually trying to do.
