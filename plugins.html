Plugins

A plugin is an installable package of AI capabilities. What belongs in a package, and how it is installed, depends on the platform.

Claude Code / Cowork

Claude plugins are installable packages that can combine skills, subagents, hooks, and MCP servers behind one manifest. They can be distributed through a marketplace repository.

/plugin marketplace add https://github.com/Aephir/Claude-Plugins
/plugin install grant-writer@waldenb-plugins

Microsoft / GitHub Copilot

Copilot does not use one plugin bundle that joins every capability. Repository instructions, agent instructions, and skills are stored as separate repository files, while MCP servers are configured independently. This keeps capabilities composable, but there is no single plugin manifest or marketplace install for the whole set.

ChatGPT

ChatGPT and Codex use a Plugin Directory to distribute workflow packages. A plugin can include skills, apps, or both; apps provide connections to external services and may use MCP. This local package is skills-only.

  1. Download and unzip it to a permanent folder.
  2. Open the ChatGPT desktop app in Work mode or Codex.
  3. Start a chat that can access the unzipped folder.
  4. Send the command below.
  5. Restart or refresh ChatGPT desktop.
  6. Open the Plugins Directory, select the personal/local source, and install Grant Writer.
  7. Start a new chat before using it.
Use $plugin-creator to add the existing Grant Writer plugin at [paste the absolute path to the unzipped grant-writer folder] to my personal marketplace.

Gemini CLI

Gemini CLI calls its installable bundles extensions. An extension can package prompts, MCP servers, custom commands, hooks, subagents, and agent skills. Extensions can be installed from a GitHub repository or a local path, and are available through the extension gallery.

Perplexity

Perplexity provides app connectors for external services and supports MCP connections where available, but it does not currently offer a general plugin bundle for combining skills, agents, hooks, and MCP servers into one installable package.
